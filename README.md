# 山手線ゲームオンライン

お題に沿った答えを制限時間内に順番に入力し、最後まで生き残るオンラインパーティーゲームです。

## プレイ

**[山手線ゲームオンラインを開く](https://yamanote-online.the-ikuma615.workers.dev)**

## 主な機能

- 2〜8人のルームコード対戦
- 同条件の相手とすぐ遊べる1対1ランダムマッチ
- 10秒・15秒・20秒の制限時間
- S・A・B・Cの難易度別お題
- 重複回答と登録済み回答の判定
- 時間切れによる脱落と観戦モード
- 最後の1人まで続くサドンデス
- 山手線30駅など、全回答を言い切った場合の生存者全員勝利

## 技術構成

- React / Next.js互換App Router
- vinext / Cloudflare Workers
- Cloudflare D1
- Drizzle ORM

## ローカル起動

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

本番用ビルド：

```bash
npm run build
```

データベース定義を変更した場合：

```bash
npm run db:generate
```

## セキュリティ

APIキー、アクセストークン、パスワードなどの秘密情報をクライアントコードへ埋め込まないでください。秘密情報が必要になった場合は、ホスティング環境のサーバー側シークレットとして管理します。

## ディレクトリ

- `app/` — 画面とゲームAPI
- `app/api/game/topics.ts` — 難易度別のお題と回答データ
- `db/` — D1のスキーマ
- `drizzle/` — データベース移行ファイル
